# 随笔记（朋友圈）功能方案

## 一、功能概述

### 1.1 定位

随笔记是一个轻量级的内容发布模块，用于分享短内容、灵感碎片、生活动态等，类似微信朋友圈的体验。与正式博客文章形成互补，满足以下场景：

| 场景 | 博客文章 | 随笔记 |
|------|----------|--------|
| 内容长度 | 长文（500字+） | 短文（140-500字） |
| 发布频率 | 低频（周/月） | 高频（日/周） |
| 内容形式 | 结构化长文 | 文字+图片+标签 |
| 互动方式 | 评论系统 | 点赞+评论 |
| 展示位置 | 文章列表 | 独立时间线 |

### 1.2 核心功能

### 2.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | ✓ | 唯一标识，格式：`moment_YYYYMMDD_HHMMSS` |
| content | string | ✓ | 笔记内容，最长 500 字 |
| images | array | - | 图片数组，最多 9 张 |
| tags | array | - | 标签数组，最多 5 个 |
| createdAt | string | ✓ | 创建时间（ISO 8601） |
| updatedAt | string | - | 更新时间 |
| status | enum | ✓ | 状态：`draft`/`published`/`archived` |
| isPinned | boolean | - | 是否置顶 |
| visibility | enum | ✓ | 可见性：`public`/`private` |
| stats.views | number | - | 浏览量 |
| stats.likes | number | - | 点赞数 |
| location | string | - | 位置信息 |
| weather | string | - | 天气信息 |

### 3.2 接口详细设计

#### 3.2.1 获取笔记列表

```
GET /api/moments?page=1&limit=20&tag=日常
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | - | 页码，默认 1 |
| limit | number | - | 每页数量，默认 20，最大 50 |
| tag | string | - | 按标签筛选 |

**响应示例：**

```json
{
  "success": true,
  "data": {
    "moments": [...],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 156,
      "totalPages": 8
    }
  }
}
```

#### 3.2.2 创建笔记

```
POST /api/admin/moments
Authorization: Bearer <token>
Content-Type: application/json
```

**请求体：**

```json
{
  "content": "今天完成了一个新功能的开发！",
  "images": ["https://img.youlainote.cn/xxx.jpg"],
  "tags": ["开发", "日常"],
  "visibility": "public",
  "location": "北京",
  "weather": "晴"
}
```

**响应示例：**

```json
{
  "success": true,
  "data": {
    "id": "moment_20260213_143052",
    "content": "今天完成了一个新功能的开发！",
    "createdAt": "2026-02-13T14:30:52.000Z"
  }
}
```

#### 3.2.3 点赞笔记

```
POST /api/moments/:id/like
X-Forwarded-For: <client-ip>
```

**响应示例：**

```json
{
  "success": true,
  "data": {
    "liked": true,
    "totalLikes": 16
  }
}
```

**防刷机制：**
- 基于 IP 地址去重
- 同一 IP 对同一笔记 24 小时内只能点赞一次
- 点赞数据存储在 `moments.json` 的 `likes` 数组中

#### 3.2.4 发表评论

```
POST /api/moments/:id/comments
Content-Type: application/json
```

**请求体：**

```json
{
  "name": "访客",
  "content": "很棒！",
  "contact": "user@example.com",
  "replyTo": null
}
```

#### 服务实现示例

```javascript
// src/server/services/moments.service.js
const path = require('path');
const { readJsonFile, writeJsonFile } = require('../utils/jsonFile');
const { generateId } = require('../utils/ids');

const MOMENTS_FILE = path.join(__dirname, '../../../public/moments.json');

const getMoments = async (req, res, next) => {
    try {
        const { page = 1, limit = 20, tag } = req.query;
        const data = await readJsonFile(MOMENTS_FILE);
        
        let moments = data.moments || [];
        
        // 筛选
        if (tag) {
            moments = moments.filter(m => m.tags.includes(tag));
        }
        
        // 只返回公开且已发布的
        moments = moments.filter(m => 
            m.status === 'published' && m.visibility === 'public'
        );
        
        // 排序：置顶优先，然后按时间倒序
        moments.sort((a, b) => {
            if (a.isPinned && !b.isPinned) return -1;
            if (!a.isPinned && b.isPinned) return 1;
            return new Date(b.createdAt) - new Date(a.createdAt);
        });
        
        // 分页
        const total = moments.length;
        const totalPages = Math.ceil(total / limit);
        const start = (page - 1) * limit;
        const paginatedMoments = moments.slice(start, start + parseInt(limit));
        
        res.json({
            success: true,
            data: {
                moments: paginatedMoments,
                pagination: { page, limit, total, totalPages }
            }
        });
    } catch (error) {
        next(error);
    }
};

const likeMoment = async (req, res, next) => {
    try {
        const { id } = req.params;
        const clientIp = req.ip || req.connection.remoteAddress;
        
        const data = await readJsonFile(MOMENTS_FILE);
        const moment = data.moments.find(m => m.id === id);
        
        if (!moment) {
            return res.status(404).json({ success: false, message: '笔记不存在' });
        }
        
        // 检查是否已点赞
        const existingLike = data.likes.find(
            l => l.momentId === id && l.ip === clientIp
        );
        
        if (existingLike) {
            // 取消点赞
            data.likes = data.likes.filter(
                l => !(l.momentId === id && l.ip === clientIp)
            );
            moment.stats.likes = Math.max(0, moment.stats.likes - 1);
        } else {
            // 添加点赞
            data.likes.push({
                momentId: id,
                ip: clientIp,
                createdAt: new Date().toISOString()
            });
            moment.stats.likes = (moment.stats.likes || 0) + 1;
        }
        
        await writeJsonFile(MOMENTS_FILE, data);
        
        res.json({
            success: true,
            data: {
                liked: !existingLike,
                totalLikes: moment.stats.likes
            }
        });
    } catch (error) {
        next(error);
    }
};

module.exports = {
    getMoments,
    likeMoment,
    // ... 其他方法
};
```

#### JavaScript 实现

```javascript
// public/js/moments.js

class MomentsPage {
    constructor() {
        this.moments = [];
        this.page = 1;
        this.loading = false;
        this.hasMore = true;
        this.currentTag = null;
        
        this.init();
    }
    
    async init() {
        await this.loadMoments();
        this.setupInfiniteScroll();
        this.setupEventListeners();
    }
    
    async loadMoments() {
        if (this.loading || !this.hasMore) return;
        
        this.loading = true;
        this.showLoading();
        
        try {
            const params = new URLSearchParams({
                page: this.page,
                limit: 20
            });
            
            if (this.currentTag) {
                params.append('tag', this.currentTag);
            }
            
            const response = await fetch(`/api/moments?${params}`);
            const result = await response.json();
            
            if (result.success) {
                this.moments = [...this.moments, ...result.data.moments];
                this.renderMoments(result.data.moments);
                
                const { pagination } = result.data;
                this.hasMore = pagination.page < pagination.totalPages;
                this.page++;
            }
        } catch (error) {
            console.error('加载失败:', error);
        } finally {
            this.loading = false;
            this.hideLoading();
        }
    }
    
    renderMoments(moments) {
        const container = document.getElementById('moments-container');
        
        moments.forEach(moment => {
            const card = this.createMomentCard(moment);
            container.appendChild(card);
        });
    }
    
    createMomentCard(moment) {
        const card = document.createElement('div');
        card.className = `moment-card ${moment.isPinned ? 'pinned' : ''}`;
        card.dataset.id = moment.id;
        
        card.innerHTML = `
            <div class="moment-content">${this.escapeHtml(moment.content)}</div>
            ${this.renderImages(moment.images)}
            <div class="moment-tags">
                ${moment.tags.map(tag => 
                    `<span class="moment-tag" data-tag="${tag}">#${tag}</span>`
                ).join('')}
            </div>
            <div class="moment-meta">
                ${this.formatDate(moment.createdAt)}
                ${moment.location ? ` · ${moment.location}` : ''}
                ${moment.weather ? ` · ${moment.weather}` : ''}
            </div>
            <div class="moment-actions">
                <span class="moment-action-btn" data-action="view">
                    👀 ${moment.stats.views}
                </span>
                <span class="moment-action-btn" data-action="like">
                    ❤️ ${moment.stats.likes}
                </span>
                <span class="moment-action-btn" data-action="comment">
                    💬 ${moment.stats.comments || 0}
                </span>
            </div>
            <div class="moment-comments" style="display: none;">
                <!-- 评论区域 -->
            </div>
        `;
        
        return card;
    }
    
    async handleLike(momentId) {
        try {
            const response = await fetch(`/api/moments/${momentId}/like`, {
                method: 'POST'
            });
            const result = await response.json();
            
            if (result.success) {
                const btn = document.querySelector(
                    `.moment-card[data-id="${momentId}"] [data-action="like"]`
                );
                btn.textContent = `❤️ ${result.data.totalLikes}`;
                btn.classList.toggle('liked', result.data.liked);
            }
        } catch (error) {
            console.error('点赞失败:', error);
        }
    }
    
    setupInfiniteScroll() {
        const observer = new IntersectionObserver((entries) => {
            if (entries[0].isIntersecting) {
                this.loadMoments();
            }
        }, { threshold: 0.1 });
        
        const sentinel = document.getElementById('scroll-sentinel');
        if (sentinel) {
            observer.observe(sentinel);
        }
    }
    
    escapeHtml(text) {
        const div = document.createElement('div');
        div.textContent = text;
        return div.innerHTML;
    }
    
    formatDate(dateStr) {
        const date = new Date(dateStr);
        return date.toLocaleDateString('zh-CN', {
            year: 'numeric',
            month: '2-digit',
            day: '2-digit',
            hour: '2-digit',
            minute: '2-digit'
        });
    }
```
