# AI 辅助编辑功能开发计划

## 一、功能概述

为博客编辑器集成 AI 辅助功能，提升文章写作效率和质量。主要包含四大核心功能模块。

---

## 二、功能模块详细设计

### 2.1 AI 文本优化（智能续写）

#### 功能描述
- **选中优化**：用户选中一段文字，右键菜单选择"AI优化"，AI 对选中内容进行润色、改写、扩展
- **智能续写**：类似 IDE 代码补全，用户输入时自动预测并提示后续内容（类似 Copilot）

#### 交互设计
```
┌─────────────────────────────────────────────────┐
│  编辑器区域                                       │
│  ┌───────────────────────────────────────────┐  │
│  │ 今天我们来讨论一下Unity3D中|              │  │
│  │                           ├─ 组件的生命周期│  │
│  │                           ├─ 对象池技术    │  │
│  │                           └─ 资源管理策略  │  │
│  └───────────────────────────────────────────┘  │
│  右键菜单：                                      │
│  ┌─────────────────┐                            │
│  │ ✨ AI 优化      │                            │
│  │ 📝 AI 扩写      │                            │
│  │ 🔄 AI 改写      │                            │
│  │ 📉 AI 精简      │                            │
│  └─────────────────┘                            │
└─────────────────────────────────────────────────┘
```

#### 技术实现要点
1. **选中优化**
   - 监听编辑器 `contextmenu` 事件
   - 获取 `Selection` 对象中的选中文本
   - 调用 AI API 进行处理
   - 弹出浮层展示多个优化版本供选择

2. **智能续写**
   - 监听 `input` 事件，防抖处理（300-500ms）
   - 获取光标位置前的上下文文本
   - 调用 AI API 生成续写建议
   - 以灰色文字显示建议内容
   - Tab 键接受建议，Esc 键忽略

#### API 设计
```javascript
POST /api/ai/optimize
{
    "text": "选中的文本内容",
    "action": "optimize | expand | rewrite | shorten",
    "context": "文章上下文（可选）"
}

Response:
{
    "success": true,
    "suggestions": [
        "优化版本1",
        "优化版本2",
        "优化版本3"
    ]
}
```

### 2.2 AI 配图生成

#### 功能描述
- 用户选中一段文字描述
- 右键选择"AI 生成配图"
- AI 根据文字内容生成符合文章风格的插图
- 自动插入到光标位置

#### 交互设计
```
右键菜单：
┌─────────────────────────┐
│ ✨ AI 优化              │
│ 🖼️ AI 生成配图          │  ← 新增
│ ...                     │
└─────────────────────────┘

配图生成弹窗：
┌─────────────────────────────────────┐
│  🖼️ AI 配图生成                      │
│  ─────────────────────────────────  │
│  描述：一只可爱的像素风格小猫         │
│  风格：[像素风] [扁平化] [手绘] [写实] │
│  尺寸：[横版16:9] [方形1:1] [竖版9:16]│
│  ─────────────────────────────────  │
│  [生成中... ████████░░ 80%]          │
│  ─────────────────────────────────  │
│  预览：                              │
│  ┌─────────┐ ┌─────────┐            │
│  │  图片1  │ │  图片2  │            │
│  └─────────┘ └─────────┘            │
│  ─────────────────────────────────  │
│        [取消]  [插入选中图片]         │
└─────────────────────────────────────┘
```

#### 技术实现要点
1. 调用图片生成 API（如 DALL-E、Stable Diffusion、Midjourney API）
2. 生成的图片保存到服务器 `/img/generated/` 目录
3. 自动生成 Markdown 图片语法插入编辑器
4. 支持重新生成、风格调整

#### API 设计
```javascript
POST /api/ai/generate-image
{
    "prompt": "图片描述",
    "style": "pixel | flat | handdrawn | realistic",
    "aspectRatio": "16:9 | 1:1 | 9:16"
}

Response:
{
    "success": true,
    "images": [
        { "id": "img_001", "url": "/img/generated/img_001.png" },
        { "id": "img_002", "url": "/img/generated/img_002.png" }
    ]
}
```

- 支持多种封面风格模板

└─────────────────────────────────────────────────┘

封面生成弹窗：
┌─────────────────────────────────────┐
│  🖼️ 文章封面生成                     │
│  ─────────────────────────────────  │

│  封面风格：                          │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│  │科技风│ │渐变风│ │极简风│ │插画风│   │
│  └─────┘ └─────┘ └─────┘ └─────┘   │
│  ─────────────────────────────────  │
│  预览：                              │
│  ┌─────────────────────────────┐    │
│  │                             │    │

│  ─────────────────────────────────  │
│      [重新生成]  [使用此封面]        │

#### 技术实现要点
1. 提取文章标题、摘要、关键词
2. 根据关键词选择合适的封面模板
3. 支持文字叠加、背景生成、装饰元素
4. 封面尺寸标准化（如 1200x630 适合社交分享）

#### API 设计
```javascript
POST /api/ai/generate-cover
{
    "title": "文章标题",
    "summary": "文章摘要",
    "keywords": ["关键词1", "关键词2"],
    "style": "tech | gradient | minimal | illustration"
}

Response:
{
    "success": true,
    "coverUrl": "/img/covers/cover_001.png"
}
```

### 2.4 AI 文章分析

#### 功能描述
- 实时分析文章质量
- 检测语法错误、错别字
- 分析文章结构、可读性
- 提供 SEO 优化建议

#### 交互设计
```
侧边栏分析面板：
┌─────────────────────────────────┐
│  📊 文章分析                     │
│  ─────────────────────────────  │
│  📈 综合评分：85/100             │
│  ─────────────────────────────  │
│  ✅ 优点：                       │
│     • 标题清晰，吸引眼球          │
│     • 段落结构合理               │
│     • 代码示例丰富               │
│  ─────────────────────────────  │
│  ⚠️ 建议改进：                   │
│     • 第3段有错别字"的→得"       │
│     • 建议添加更多小标题          │
│     • 摘要字数偏少，建议50-100字  │
│  ─────────────────────────────  │
│  🔍 SEO 检查：                   │
│     • 标题长度：✅ 适中          │
│     • 关键词密度：⚠️ 偏低        │
│     • 内链数量：❌ 无            │
│  ─────────────────────────────  │
│  [一键修复] [查看详细报告]        │
└─────────────────────────────────┘
```

#### 技术实现要点
1. **实时分析**：防抖调用，用户停止输入 2 秒后触发
2. **错别字检测**：调用 NLP 接口或本地词典
3. **可读性分析**：计算句子长度、段落长度、专业词汇比例
4. **SEO 分析**：标题长度、关键词密度、Meta 描述

#### API 设计
```javascript
POST /api/ai/analyze
{
    "title": "文章标题",
    "content": "文章内容",
    "tags": ["标签"]
}

Response:
{
    "success": true,
    "score": 85,
    "strengths": ["优点1", "优点2"],
    "improvements": [
        {
            "type": "typo",
            "position": { "line": 3, "column": 15 },
            "original": "的",
            "suggestion": "得",
            "message": "建议修改错别字"
        }
    ],
    "seo": {
        "titleLength": "good",
        "keywordDensity": "low",
        "internalLinks": 0
    }
}
```

## 三、技术架构

### 3.1 前端架构
```
editor.html
    │
    ├── editor.js (主编辑器逻辑)
    │
    ├── ai-assistant.js (AI 辅助模块)
    │   ├── textOptimizer.js    (文本优化)
    │   ├── imageGenerator.js   (配图生成)
    │   ├── coverGenerator.js   (封面生成)
    │   └── articleAnalyzer.js  (文章分析)
    │
    └── ai-ui.js (AI 相关 UI 组件)
        ├── contextMenu.js      (右键菜单)
        ├── suggestionPopup.js  (建议浮层)
        └── analysisPanel.js    (分析面板)
```

### 3.2 后端架构
```
server.js
    │
    └── /api/ai/
        ├── optimize.js      (文本优化接口)
        ├── generate-image.js (图片生成接口)
        ├── generate-cover.js (封面生成接口)
        └── analyze.js       (文章分析接口)
```

### 3.3 AI 服务选型

| 功能 | 推荐方案 | 备选方案 |
|------|----------|----------|
| 文本优化 | OpenAI GPT-4 | Claude API、文心一言 |
| 智能续写 | OpenAI GPT-4 | 通义千问 |
| 配图生成 | DALL-E 3 | Stable Diffusion、Midjourney |
| 封面生成 | DALL-E 3 + 模板叠加 | Canva API |
| 文章分析 | GPT-4 + 本地规则 | 自建 NLP 模型 |

## 六、注意事项

1. **API Key 安全**：前端不直接存储 API Key，通过后端代理调用
2. **费用控制**：设置每日调用上限，超出后降级处理
3. **用户体验**：所有 AI 操作提供加载动画，支持取消操作
4. **数据隐私**：文章内容仅在用户主动触发时发送给 AI 服务
5. **离线降级**：AI 服务不可用时，编辑器核心功能正常使用
