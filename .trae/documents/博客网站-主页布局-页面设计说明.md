# 主页（仅布局）页面设计说明（桌面优先）

## 1) Layout
- 栅格：12 栏 CSS Grid（内容最大宽度 1200px，左右留白自适应；主体区 `gap: 24px`）。
- 页面结构：顶部导航（满宽） + 主体（居中容器） + 页脚（满宽）。
- 主体分区：采用“上-中-下”堆叠区块；区块内部多用卡片网格。
- 响应式（可选）：
  - ≥1200px：两/三列卡片网格；文章列表可 2 列。
  - 768–1199px：主要区块变 1–2 列。
  - <768px：全部单列堆叠（但本需求以桌面优先为主）。

## 2) Meta Information
- Title：博客主页
- Description：包含天气占位、专栏入口、留言入口、文章留言入口与吃货模块的主页布局。
- Open Graph：
  - og:title=博客主页
  - og:description=博客网站主页布局
  - og:type=website

## 3) Global Styles（设计令牌）
- 颜色：
  - Background：#0B1220（深色背景）或 #F7F8FA（浅色背景，二选一，全站统一）
  - Surface/Card：#111827（深）/ #FFFFFF（浅）
  - Primary：#3B82F6；Hover：#2563EB
  - Text：#E5E7EB（深）/ #111827（浅）；Secondary：#9CA3AF
  - Border：rgba(255,255,255,0.08) 或 #E5E7EB
- 字体：
  - 基础字号 16px；H1 32px，H2 24px，H3 20px，Body 16px，Caption 12–14px
- 按钮：
  - Primary：实心主色 + 白字；hover 加深；disabled 降低透明度
  - Secondary：描边按钮（用于“留言入口/查看详情”等次操作）
- 卡片：圆角 12px；阴影轻量；padding 16–20px
- 链接：正文内链接使用主色，下划线 hover 出现

## 4) Page Structure（主页信息架构）
1. 顶部导航区
2. 首屏导语/站点简介（可选但建议占位）
3. 天气组件占位 + 留言入口（并排双列）
4. 文章区（含文章留言入口）
5. 专栏入口区
6. 吃货模块
7. 页脚

## 5) Sections & Components（逐区块规格）

### 5.1 顶部导航（Header / Nav）
- 结构：左侧 Logo/站名；右侧导航链接：主页、专栏、留言板。
- 交互：当前页高亮；hover 改变文字颜色或底部描边。

### 5.2 首屏导语（Hero，占位）
- 组件：标题（H1）+ 一行简介（Body）+ 右侧可选插画占位。
- 目的：建立站点定位（博客/专栏/美食分享等占位文案）。

### 5.3 天气占位卡片（Weather Placeholder Card）
- 卡片内容：
  - 标题：动态天气（占位）
  - 三行信息占位：城市/温度/天气描述
  - 图标占位：圆形或 48x48 方块 skeleton
- 状态：加载态 skeleton（灰块）+ 默认态占位文案。

### 5.4 留言入口卡片（Message Board Entry）
- 卡片内容：
  - 标题：留言板
  - 说明：写下你的想法（占位）
  - CTA：按钮“去留言” → 跳转 `/message-board`
- 视觉：与天气卡片同高度，形成并排双卡。

### 5.5 文章区（Post List + Comment Entry）
- 区块标题：最新文章
- 列表样式：卡片网格（桌面 2 列）或纵向列表（更偏内容阅读）。
- 单卡元素：
  - 标题（H3）
  - 摘要 2–3 行（截断）
  - 元信息：日期/作者（占位）
  - 操作区：
    - 次按钮：查看详情 → `/posts/:id`
    - 次按钮：留言入口 → `/message-board`（仅入口，不实现关联逻辑）

### 5.6 专栏入口区（Columns Entry）
- 区块标题：专栏
- 内容：3 张专栏卡片占位（封面矩形 + 专栏名 + 简介 1 行）。
- 入口：
  - 区块右侧“查看全部”链接 → `/columns`
  - 专栏卡片可点击（链接占位）。

### 5.7 吃货模块（Foodie Module）
- 区块标题：吃货时间
- 结构：左侧主推大卡（图片占位 16:9 + 标题/摘要）+ 右侧 2–4 张小卡列表。
- 内容元素：标签 chips（如“探店/食谱/清单”占位）、评分/地点等信息不做功能，仅留排版位置。

### 5.8 页脚（Footer）
- 左：版权占位
- 右：链接占位（关于/联系/隐私）

## 6) Interaction & Motion（可选）
- hover：卡片上浮 2px + 阴影加深；按钮 hover 颜色加深。
- 过渡：`transition: 150ms ease`（仅用于 hover，避免复杂动画）。
