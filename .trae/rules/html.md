# 界面说明

本文档汇总了 YOULAI_BLOG 项目的所有界面文件，并为每个界面分配了唯一编号。

| 编号 | 文件路径 | 界面名称 | 描述 |
| :--- | :--- | :--- | :--- |
| 01 | `public/index.html` | 首页 | 博客网站的主页，展示个人介绍和最新文章列表。 |
| 02 | `public/admin.html` | 管理后台 | 管理员后台，用于文章管理、留言审核等。 |
| 03 | `public/columns.html` | 专栏列表 | 展示博客的所有专栏分类。 |
| 04 | `public/editor.html` | 文章编辑器 | 用于撰写和编辑 Markdown 文章的界面。 |
| 05 | `public/login.html` | 管理员登录 | 后台管理系统的登录界面。 |
| 06 | `public/message-board.html` | 留言板 | 访客留言和交流的页面。 |
| 07 | `public/post.html` | 文章详情页 | 展示单篇文章内容的模板页面。 |
| 08 | `public/discovery.html` | 发现页面 | 展示标签云，提供内容发现功能。 |
| 09 | `public/portfolio.html` | 作品集页面 | 展示独立作品和项目案例。 |
| 10 | `public/about.html` | 关于页面 | 展示个人介绍和网站信息。 |
